# Security Policy

Run the local Repair demo with trusted, server-configured fixtures. Keep development sessions and credentials in private local files.

For vulnerabilities in this project's Repair additions, use **Security → Report a vulnerability** on this repository when available. Otherwise, open an issue requesting a private contact channel and share vulnerability details privately.

For vulnerabilities in upstream Open SWE, follow the [upstream security policy](https://github.com/langchain-ai/open-swe/security/policy).
